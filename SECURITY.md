# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Umi‑Time — whether in the core TypeScript library, the documentation site, or any solar‑geometry code — please report it responsibly.

Please email:

**security@umitime.com**

We will acknowledge your report within a reasonable timeframe and work with you to understand and resolve the issue.

---

## Supported Versions

Umi‑Time is under active development.  
At this stage, **only the latest commit on the `main` branch** is considered supported.

Once versioned releases begin, this section will expand to list supported release ranges.

---

## Responsible Disclosure

We ask that you:

- Privately disclose vulnerabilities to the maintainers  
- Avoid posting details publicly until a fix is released  
- Provide clear reproduction steps  
- Include environment details (browser, OS, Node version)  
- Include any relevant Umi‑Time input values or configuration  

This helps us ensure fixes are applied safely and quickly.

---

## Security Areas

The following components are covered by this policy:

- **Core TypeScript library** (`packages/umi-time-js`)  
- **Solar geometry calculations**  
- **Formatting and parsing logic**  
- **Documentation site** (`www`)  
- **Interactive demos**  
- **Build tooling and CI workflows**  

If your report touches any of these areas, it falls under this policy.

---

## Non‑Security Issues

For bugs, feature requests, or documentation improvements, please open an issue on GitHub instead of emailing the security address.

---

## Thank You

Security researchers and contributors help keep Umi‑Time safe for everyone.  
We appreciate your efforts and responsible disclosure.
