# Umi‑Time

Umi‑Time is an open standard for presenting UTC in a locally meaningful way.  
This organization hosts the official specification, reference implementations, and documentation.

The project is fully open‑source and welcomes contributions across all repositories.

---

## Repositories

### **spec**
The formal Umi‑Time Standard, published under **CC‑BY‑4.0**.  
This is the only repository with **GitHub Discussions** enabled.

### **www**
The documentation website and interactive demos, built with **Astro** and licensed under **MIT**.

### **umi-time-js**
The official TypeScript reference implementation, licensed under **MIT**.  
Provides solar geometry, formatting, parsing, and core Umi‑Time calculations.

### **umi-time-XXX**
More official reference implementations for other languages will be added soon.

## Contributing

Umi‑Time is a community-driven project.  
We welcome contributions in the form of issues, discussions, documentation improvements, and pull requests.

Each repository contains its own **CONTRIBUTING.md** with repo‑specific instructions:

- Spec contributions focus on clarity, correctness, and rigor.  
- Library contributions focus on implementation quality and test coverage.  
- Website contributions focus on documentation, demos, and accessibility.

For organization-wide guidelines, see: [CONTRIBUTING.md](CONTRIBUTING.md)

---

## Discussions

Only the **spec** repository has Discussions enabled.  
Use Discussions for:

- Conceptual questions  
- Clarification of definitions  
- Proposals for changes to the standard  
- Early-stage design exploration  

Implementation questions should be opened as issues in `umi-time-js` or `www`.
