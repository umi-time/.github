# Feature Request

## User Story
Please describe the need for the feature in user-story format:

**As a** *type of user*  
**I need** *an ability that is not yet available*  
**So that** *what having that ability would accomplish for the user*

This helps maintainers understand the underlying need before evaluating solutions.

Provide a clear description of the feature you are proposing.

## Motivation
Explain why this feature is useful or necessary.
